# Willow & Fern website

This is a single-file, responsive website.

## Preview
Open `index.html` in a browser.

## Free publishing
You can publish this folder with GitHub Pages. Create a GitHub repository, upload `index.html`, then enable Pages from the repository settings.

The site includes:
- Home / hero section
- About section
- Full menu with prices supplied for the project
- Address and Google Maps directions
- Click-to-call phone number
- Hours
- Mobile responsive design

The address, phone number, and hours were supplied/verified for the project; verify business details before using this as an official public website.
